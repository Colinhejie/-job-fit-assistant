## 6. 分步骤耗时与缓存

| 阶段 | 耗时 | 缓存 |
|---|---|---|
| 单元测试 76 项 | ~0.5s | 无 |
| 内置自检 | ~1.4s | 无 |
| 端到端 56 项 | ~43s | 无 |
| 验收（单样本集，50 项） | ~240s（回归集 231s / 最终集 245s） | 无 |
| 其中 T40 三次语义链重复 | 约 60% 的本集耗时 | **无缓存层，三次均为冷运行**，每次都重新执行 事实→映射→改写→导出 |

本工具不缓存解析结果、不缓存模型输出；同一输入重复运行只会重复计算。
宿主侧的模型调用是否缓存，取决于宿主，不在本工具控制范围。

## 7. 剩余发布阻断项

1. **真实 OCR 部分验证**：5 类文件 6 通过 1 失败（`JMeter` 漏识）；PP-StructureV3 未验证。
2. **真实宿主浏览未验证**——串页防护只在"能拿到页面文本"的前提下有效。
3. **简历语义质量未验证**——没有独立人工签署；本轮审计中我自己就发现过 3 处
   自动规则没拦住的表述问题（"专题分析"、"习惯…"、"报表体系"）。
4. 不得宣称机械规则能保证不编造：它只能证明"没有命中已知模式"。
