# Work 客户端：安装与真实读取测试步骤

> 本文件是**给用户执行**的步骤，不是测试结果。当前没有可用的 Work 客户端与浏览器工具，
> 因此第 4 节所有项目状态为**未测试**。

## 1. 安装与启用 Skill

不清楚具体客户端版本时，按下面通用路径找，**不要假设菜单名**：

1. 打开 Work 客户端 → 设置/偏好 → 找到"Skills / 技能 / 扩展"一类入口；
2. 把 `job-fit-assistant/` 整个目录放入客户端的 skills 目录（或按其文档导入）；
3. 确认 `SKILL.md` 的 frontmatter 被识别（`name: job-fit-assistant`）；
4. 在对话里输入"帮我针对这个岗位改简历"，确认技能被触发；
5. 记录：客户端名称 + 版本号、Skills 目录的绝对路径、是否成功触发。

若客户端不支持本地技能目录，把 `SKILL.md` 内容作为系统提示/项目说明加载，并保证
`scripts/` 可在其终端里执行（`python scripts/jfa.py scan`）。

## 2. 环境自检（在客户端终端里跑）

```bash
python --version                       # 需要 3.10+
python job-fit-assistant/scripts/jfa.py scan
```

把 `scan` 的九行输出原样记录。**"浏览器"一行在声明前必然是"未声明"，这是对的。**

## 3. 声明真实浏览器能力（不虚构工具名）

看一眼客户端实际暴露了哪些工具，然后：

```bash
python job-fit-assistant/scripts/jfa.py host declare \
  --browser-kind <你看到的类型> --tool <真实工具名> --login-scope local
```

如果客户端没有任何浏览器类工具，**不要声明**，直接走"粘贴职位文本"。

## 5. 真实 BOSS 的前置条件

同时满足才做：

1. 你自己有账号并**自己登录**；
2. 平台条款允许读取公开职位信息；
3. 只读约定范围（标题/公司/地点/职责/要求/薪资），单次 ≤ 8 条；
4. 不打招呼、不投递、不改在线简历；
5. 遇风控立即停止。
