# OCR 核对流程

识别结果不等于事实。这一节定义"机器读到的字"如何变成"用户确认的字"。

## 1. 队列怎么产生

`jfa ingest` 之后自动生成 `review/<source_id>.json`，条目来自：

- `check_status` 为 `needs_review` 或 `unverified` 的块；
- 即：OCR 结果、文本框内容、低置信度（< 0.75）、乱码、过短片段、异常日期、阅读顺序冲突。

每条含：`item_id`、`block_id`、`page`、`method`、`confidence`、`text`、`spans`、`page_image`、`flags`。

## 2. 重点字段自动标出

`spans` 是带位置的高亮，类别有：

| 类别 | 匹配对象 | 为什么必须核对 |
| --- | --- | --- |
| `name` | `姓名：X` 后的人名 | 最不能错的字段 |
| `contact` | 邮箱、手机、固话 | 错一位就联系不上 |
| `company` | 带"有限公司/集团/科技"的公司名 | 不得按上下文补全 |
| `school` | 带"大学/学院/学校"的院校名 | 不得推测 |
| `degree` | 博士/硕士/本科/大专… | 学历不得由上下文推断 |
| `date` | `2021.03`、`2019年6月` 等 | 异常日期会污染年限计算 |
| `number` | 带单位/百分号的数字 | 业绩数字不得编造或改写 |
| `garbled` | `�`、`□` | 需人眼确认原文 |

## 3. 展示方式

```bash
python scripts/jfa.py --home <ws> ocr show <source_id> --limit 40
```

输出 markdown：每条给页码、方法、置信度、原件位置（渲染页 PNG 路径）、识别原文、标记原因、需重点核对的片段。

引用时**必须同时给图和字**：只给文字等于让用户对着一份可能已经错了的东西点头。若 `page_image` 为空（例如 DOCX 文本框），要说明"该内容来自文档内部结构，无可引用图像，请对照原文件查看"。

## 4. 三种决定

```bash
python scripts/jfa.py --home <ws> ocr accept  <sid> <item_id>                  # 确认无误
python scripts/jfa.py --home <ws> ocr correct <sid> <item_id> --text "正确文字" --note "月份应为 12"
python scripts/jfa.py --home <ws> ocr reject  <sid> <item_id> --note "这是页脚水印"
```

- `correct` 后的更正**不覆盖**识别原文：`revisions` 里保留 `before`/`after`/`at`/`note`，块文本用更正后的值，并在 `notes` 里留 `[原文: ...]`。
- `reject` 表示这段不是有效内容（水印、页码、装饰），下游构建事实时会排除。
- 每次决定都追加一行到 `review/corrections.jsonl`，供事实检查清单复盘。

## 5. 必须标待确认的情形

1. 置信度低于阈值；
2. 出现不可显示字符或明显乱码；
3. 日期不可能（月份 > 12、年份超出 1950–今年+10）；
4. 同一页的块顺序与纵坐标矛盾（阅读顺序冲突）；
5. 坐标框退化（宽或高 ≤ 0）。

任何一条命中，该块就不能直接进入事实档案的"已确认"状态。

## 6. 绝对不要做的事

- **不要根据上下文猜学历、公司或业绩数字。** 例如识别出"云帆大"不要自动补成"云帆大学"；识别出"2021.0"不要猜是 `.03` 还是 `.06`。标记 + 问人。
- **不要因为"看起来合理"就 accept。** 队列存在的意义就是让用户看那一眼。
- **不要用更正功能批量"洗"数据。** 一次更正对应一次真实判断。
- **不要在没有核对的情况下调用 `facts build` 后直接导出。** 未确认事实要么被排除，要么被标为待确认，简历会变得很薄——那正是当前信息量的诚实反映。

## 7. 与事实档案的衔接

`facts build` 读取的是「应用更正后」的块：`reject` 的块被跳过，`correct` 的块用更正文本。原始 `<sid>.jsonl` 永远保持机器识别原样，可随时回溯"当初机器读成了什么"。

用户核对完成后，仍需在事实档案层面确认结构化字段（公司/职位拆分等），两者是不同层次的确认：

- 块级确认 = "这几个字读对了"；
- 事实级确认 = "这条经历就该这么写"。
