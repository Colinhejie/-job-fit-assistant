# 可选 OCR 依赖（固定版本）
#
# 版本对齐 PaddleOCR 3.x 官方文档：
#   https://www.paddleocr.ai/v3.4.1/quick_start.html
#
# ⚠ 本仓库的测试环境**没有安装**这两个包，因此"真实 OCR 识别"这一项
#   状态为「未验证」。安装后 `jfa scan` 会自动把 OCR 标为可用。
#
# 安装顺序（CPU，Windows / Linux / macOS 通用）：
#   1) python -m pip install paddlepaddle==3.2.0 -i https://www.paddlepaddle.org.cn/packages/stable/cpu/
#   2) python -m pip install paddleocr==3.4.1
#
# GPU：把 paddlepaddle 换成 paddlepaddle-gpu==3.2.0，并按 CUDA 版本选源：
#   https://www.paddlepaddle.org.cn/packages/stable/cu118/
#
# 首次运行会自动下载模型到 ~/.paddlex/official_models：
#   - PP-OCRv5 文本检测 + 文本识别（简体中文）
#   - PP-StructureV3 版面结构模型（仅 --structure 时需要）
#   合计约数百 MB，需要联网一次，之后可离线。
#
# 资源需求：
#   - 内存：≥ 2GB 可用（PP-StructureV3 建议 ≥ 4GB）
#   - CPU：整页 A4 约数秒到十几秒
#   - 磁盘：模型缓存约 1–2GB
#
# 轻量替代（无版面结构分析，精度略低）：
#   pip install rapidocr_onnxruntime
#
# 系统级替代（需另装中文语言包，中文效果一般）：
#   tesseract + tessdata chi_sim。程序会自动探测 PATH 中的 tesseract。

paddlepaddle==3.2.0
paddleocr==3.4.1
